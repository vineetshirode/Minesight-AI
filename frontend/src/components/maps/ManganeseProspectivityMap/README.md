# ManganeseProspectivityMap Component

This directory contains the modular geospatial Leaflet map component for MineSight AI manganese prospectivity visualization.

## Files
- `ManganeseProspectivityMap.jsx`: Main React map component wrapper.
- `ManganeseProspectivityMap.css`: Styles for map container, legend, and controls.
- `mapLayers.js`: Leaflet tile layers (Terrain, Satellite, Topo) and layer controls.
- `prospectivityRenderer.js`: Spatial raster and canvas rendering engine for Model 1 prospectivity.
- `gridUtils.js`: Spatial grid calculations and coordinate conversions.
- `colorScale.js`: Continuous color ramp mappings (Low / Med / High).
- `labels.js`: Geographic markers, district coordinates, and regional labels.
- `README.md`: Component documentation.
